【GitHub Desktopで更新する場合】
1. このフォルダの中身をすべて選択してコピーする。
2. GitHub Desktopで対象リポジトリを開く。
3. Repository → Show in Explorer を押す。
4. 開いたリポジトリ直下へ、このフォルダの中身を貼り付ける。
5. 同名ファイルは「ファイルを置き換える」を選択する。
6. GitHub Desktopへ戻り、Summaryに例として「iPhone mobile UI fix」と入力する。
7. Commit to main → Push origin を実行する。

※ index.html がリポジトリ直下にある状態にすること。
※ このフォルダそのものをリポジトリ内へ入れないこと。

【iPhone側の更新】
1. GitHub PagesのURLをSafariで開く。
2. 数十秒待ってGitHub Pagesの更新が反映されたことを確認する。
3. Safariでページを再読み込みする。
4. 「オフライン準備」が表示された場合は、完了まで通信を切らない。
5. 旧画面が出る場合はSafariを完全終了して再度開き、もう一度再読み込みする。
6. ホーム画面へ追加済みの場合、通常は追加し直す必要はない。
7. 最後に機内モードで起動し、画像・音声・セーブを確認する。

【操作】
・横画面でプレイする。
・左スティック：移動
・右下の走るボタン：走行ON/OFF
・右下のどうぐボタン：どうぐ使用
・どうぐ欄：タップで選択、同じ欄を素早く2回タップで捨てる
・画面上の近くの対象：タップして調べる/奉納
・上中央：ポーズ
