夜道の追跡者 神域 — スマホ専用ソロ版 rev198-mobile

概要
- ソロプレイ専用です。マルチプレイ、ロビー、サーバー、WebSocket通信は含みません。
- 操作はスマホ向けタッチ操作に統一しています。

起動
1. index.html をブラウザで開きます。
2. 警告画面をタップしてタイトルへ進みます。
3. 「はじめる」をタップします。

スマホ操作
- 移動：左下スティック
- 走る：右下の走るボタンでON/OFF
- 調べる・箱を開ける・奉納・社の力：対象に近づいて対象そのものをタップ
- どうぐ選択：画面上部のどうぐ欄をタップ
- どうぐ使用：右下のどうぐボタン
- どうぐを捨てる：どうぐ欄を素早く2回タップ
- 小石・爆竹：どうぐボタンを押しながらスティックで方向を決め、指を離す
- 小さな仏像：どうぐボタン長押し
- ポーズ：画面上部中央の「ポーズ」

反撃モード
- タイトル画面の「あいことば」をタップすると入力欄が開きます。
- 「反撃」と入力：反撃モード
- 「通常」と入力：通常モード
- 選択したモードは端末内に保存され、次回起動時にも維持されます。

反撃モードの銃系道具
- 魔封銃・魔封ロケットランチャー：どうぐボタンを1回タップで構える
- 構え中にどうぐボタンを1回タップ：発射
- 構え中にどうぐボタンをスワイプ：構え解除
- 魔封銃の弾薬補充：「リロード」ボタン

主なファイル
- index.html : ゲーム画面
- game.js : ソロゲーム本体
- counterattack.js : 反撃モード
- style.css : 表示・スマホ操作UI
- assets/ : 画像・音声
- cheat_commands.txt : 開発・検証用チート一覧
